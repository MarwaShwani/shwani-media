# تصاميم منشورات SHWANI COMPANY

هذا المجلد يحوي مصدر كل شريحة نُشرت على حساب انستغرام shwanicompany، ويعيد إنتاجها بالضبط.

- `rounded.py`: رسم شعار SHWANI بحروف مستديرة الأطراف، ووصلة حرف H بلون التيراكوتا.
- `common.py`: قواعد الشرائح المشتركة: المقاس 1080×1350، الخط Alexandria، الألوان، الشريط العلوي والسفلي. `page(..., light=True)` تعطي الخلفية الحليبية. التصدير يتوقف إن لم يُحمَّل خط Alexandria، فلا تخرج شريحة بخط بديل.
- **أحجام الخط للهاتف (قاعدة، 20 أكتوبر):** العناوين 84 بكسل فما فوق، والنص 44 فما فوق، ولا شيء تحت 36 (حتى الترقيم والمعرّف والشارات). فحص المنشور 10 (`check_marks`) يتوقف عند أي نص أصغر، وعند أي كبسولة زخرفية خلف نص.
- `posts/NN/build.py`: شرائح كل منشور. التشغيل يحفظ `slide-1.png` وما بعدها في المجلد نفسه.
- `captions.json`: نص كل منشور، ووصف الصور، وموعده.

## التشغيل

```bash
cd design
npm install --no-save @fontsource/alexandria   # الخط
pip install playwright pillow                  # إن لم تكن مثبتة
python3 posts/02/build.py
```

الصور النهائية المنشورة محفوظة في `../posts/<التاريخ>-<الرقم>-<الاسم>/`، ومنها تُؤخذ روابط النشر.
